I added the **Notes** page to give small work notes a stable home: a bug I just fixed, a way I organise code, or a file I want to share again.

## What will I write here?

- Technical notes about web, mobile and desktop.
- How I use AI in my workflow.
- A build log for my first game.

Every note has **two versions** — Vietnamese and English — and you can switch between them at the top of the article. Both are written by me, not run through a translator.

## Format

Posts are Markdown, so they have headings, lists, links and code blocks:

```ts
const note = {
  title: "A short note",
  tags: ["Next.js", "AI"],
};
```

If you want to write a new post, the article writing guideline is in the downloads section below.
