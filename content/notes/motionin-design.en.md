Motion (motionin.design) is a library of 54 interactive web sections, aimed mainly at photography and portfolio sites.

## What is in it

The gallery holds sections such as image walls, heroes, lookbooks and portfolios. Each entry has a working demo and an implementation note: `requestAnimationFrame` clocks, GSAP, shaders, displacement maps, refraction following Snell's law.

A few examples:

- **Aperture** — an auto-scrolling photo wall that bows the images like a lens.
- **Moments** — a photo wall pulled towards the cursor.
- **Boutique** — a spherical 3D lookbook.
- **Cabinet** — a portfolio built as an arcade machine.
- **Desk 95** — a portfolio laid out as a Windows 95 desktop.
- **Atlas** — an explorable 3D globe, country by country.

## Which ecosystem it belongs to

The site's assets are served from `motion.cdn.modulify.website`, and the footer points at `modulify.ai`.
